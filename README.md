# hiccai-wenan

商业文案与品牌创意 Skill，v4.1.0。适用于 Codex、Claude Code 等可读取 SKILL.md 的助手。

根据目标、受众、购买阶段、媒介、品牌语气和真实证据写作：需要卖货时推进购买决策，需要品牌时建立辨识度，需要两者时让创意承接购买理由。

## 本版改进

- 海报按位置与现成画面安排主标题、副标题、图注和行动入口，上图字可直接分行交付。
- 商品主图、详情首屏和后续卖点屏分别回应识别、选择和验证问题。
- 从顾客原话、犹豫和动作提炼口语表达，区分真实引文与创作对白。
- 按停留、转发、收藏、关注选择内容，获客文案交代咨询入口、所需信息和服务范围。
- 借热点时核对时间、平台和原语境，按品牌关系及物料使用周期决定是否采用。
- [25个行为评估场景](test-prompts.json)覆盖原有任务及以上改动。

## 安装

把本目录（含 SKILL.md 和 references）放入你的技能目录。Codex通常为 `~/.codex/skills/hiccai-wenan`，Claude Code通常为 `~/.claude/skills/hiccai-wenan`。已有版本先备份再替换。

## 使用

直接提出任务，例如：

> 给山茶记写一张办公室外卖海报。现萃原叶茶，3杯45元，小程序下单。要有巧思，也要促进购买，只给一个最佳版本。

> 优化这段销售文案，先解决客户觉得不值的问题；不要增加未经证实的承诺。

> 给这个品牌想一个国际广告奖水准的静态海报创意，预算只够平面制作。

## 验证

每题只把 `prompt` 交给加载了本技能的新会话，得到成稿后再按对应的 `acceptance` 逐项检查。前14题覆盖既有场景，15—25题覆盖跨媒介上版、已有配图、详情分屏、用户原话、传播动作、咨询服务边界和借势。热点题自带时间背景或离线条件，复测时可原样使用。

比较版本时保持模型和输入一致，盲评对题、可信、品牌关联和表达质量。技能测试检验能否交出可用成稿。判断实际传播或销售效果时，结合投放目标分别看转发、收藏、关注、有效咨询或成交。
