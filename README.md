## 双轨执行机制与五阶段工作流

- **轨道 A｜定向快速通道（Fast-Track）**：简单改句、直接促销/通知、纯规格说明、私域单句回复，或用户指定「只给结果 / 只给一句 / 只要标题 / 只给上图文字」时，按需只读 1 个规范并在**内部静默跑完红队审稿与重写**，直接交付干净可用的终稿，绝不强行暂停或输出多余策略。
- **轨道 B｜现象级爆款全案工作流（Stage 0 → Stage 4）**：开放式品牌主张、爆款社媒内容、公众号爆文、TVC 品牌大片或整合传播全案严格执行五阶段：
  1. **Stage 0 简报对准 & 反向挖料门控**：仅给宽泛主题或缺少核心事实时，先用 1~3 个锋利问题挖真料（支持「按默认假设起跑」快捷出口，未知硬事实用占位，绝不编造）。
  2. **Stage 1 时代情绪水位 & 核心命题拆解**：锁死“对这个人、在这个场景，凭什么相信这一件事”，按需落位四层阶梯，拆解标杆传播机制。
  3. **Stage 2 三维度「现象级核弹切口」（默认门控暂停）**：输出 3 个方向真正不同的锋利切口（高概念钩子 / 情绪与嘴替 / 超级模因与社交货币 / 二创与行动收口 / 去 Logo 不可替代测试），等待用户选定（嫌太安全立刻追加第 4 个高冒险方案）。
  4. **Stage 3 按需加载单一载体规范输出成品 + 扩散包**：仅读对应 1 个规范，按 `[HOOKS]`、`[MAIN_OUTPUT]`、`[VIRAL_CLIPS]`、`[COMMENTS]`、`[SPREAD_PATH]` 输出完整可落地交付物。
  5. **Stage 4 硬约束零容忍 + 五维 10 分制红队审稿 & 强制重写**：先查事实/字数/格式/合规死线，再按五维硬核打分卡自审，**任一单项 `< 8` 分整段推翻重构**，简述改掉的 3 个致命病灶后交付全项 `≥ 8.5` 分的「2.0 终稿」。
