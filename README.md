# hiccai-wenan

商业文案与品牌创意 Skill，v4.0.0。适用于 Codex、Claude Code 等可读取 SKILL.md 的助手。

根据目标、受众、购买阶段、媒介、品牌语气和真实证据写作：需要卖货时推进购买决策，需要品牌时建立辨识度，需要两者时让创意承接购买理由。

## 本版改进

- 用需求与事实约束替代所有任务强制套洞察的规则。
- 从不同创意方向中选优，检查品牌关联、可理解性和执行条件。
- 补充电商、促销、直播、私域、B2B与高端销售的购买障碍处理。
- 保留高端表达的分寸，取消所有奢侈品必须同一种语气的限制。
- 参考官方广告奖评审维度打磨作品，不承诺获奖或转化结果。
- 14个行为评估场景覆盖任务适配、销售、原创与事实边界。

## 安装

把本目录（含 SKILL.md 和 references）放入你的技能目录。Codex通常为 `~/.codex/skills/hiccai-wenan`，Claude Code通常为 `~/.claude/skills/hiccai-wenan`。已有版本先备份再替换。

## 使用

直接提出任务，例如：

> 给山茶记写一张办公室外卖海报。现萃原叶茶，3杯45元，小程序下单。要有巧思，也要促进购买，只给一个最佳版本。

> 优化这段销售文案，先解决客户觉得不值的问题；不要增加未经证实的承诺。

> 给这个品牌想一个国际广告奖水准的静态海报创意，预算只够平面制作。

## 验证

`test-prompts.json` 中每项包含请求和行为验收条件。新会话加载技能后执行同一请求，按条件检查，不以出现某句指定文案为通过标准。比较版本时保持模型和输入一致，盲评对题、可信、品牌关联和表达质量。结构检查通过不代表已证明真实转化提升。
