# 规范模块：高创意标准 / 国际广告奖水准 / 反事实与原创审查

> 当用户提出「全球广告大奖水准」「冲奖创意」「有突破的 campaign」「戛纳/D&AD 级打磨」或要求做深度原创性与策略校验时，按需追加读取本文件。

## 1. 评审依据与适用边界
截至 2026-09-11 核对的官方资料：
- [Cannes Lions Outdoor：What You Need to Know](https://www.canneslions.com/awards/lions/outdoor/what-you-need-to-know)：该类别关注 `idea`、`execution`、`impact`。
- [Cannes Lions Entry Guide](https://www.canneslions.com/awards/awards-support/awards-entry-guide)：评审与提交材料须按具体类别查阅，不可把单一类别标准泛化到全部类别。
- [D&AD 2026 Entry Kit](https://media.dandad.org/documents/Entry_Kit_2026_EN_1.pdf)：包含创意启发性与执行工艺等评审维度，各类别侧重不同。
- [D&AD Impact 2026](https://campaigns.dandad.org/knowledge-base/how-are-entries-judged-for-the-dad-impact-awards-2026)：Impact 类别另关注真实变化、概念验证、可扩展性与商业可行性，不能泛化为每条商业文案都要绑定社会议题。

> 以上用于构建内部高标准创意检查，不是官方统一评分表，**严禁模拟获奖认证或预测获奖概率**；若真要参赛，须重新核对当年类别、资格与提报规则。

## 2. 把想法压成可检验的一句话命题
在进入 Stage 3 执行前，用一句大白话说清：**利用哪个真实发现，通过什么表达/动作，让受众重新理解品牌的什么价值。**
- 若只能说出“引发共鸣”“打破边界”“传递态度”“唤醒内心”，说明还没有找到真正的创意，必须打回重想。
- 允许带张力的简洁陈述，不强制戏剧反转或宏大情绪片；最锋利的一句可以来自产品实证，也可以来自文化观察，不能只奖励单一美学。
- **预算与媒介纪律**：用户预算只够一张静态海报或只要一句 Slogan 时，就在静态海报或一句 Slogan 里做到极致，**绝不擅自扩成大型装置、公益项目或昂贵事件片**。

## 3. 六维创意证据对比表（配合 Stage 2 筛选与 Stage 4 红队）

| 检查维度 | 合格标准（要看到什么） | 失败时怎么改 |
| :--- | :--- | :--- |
| **对题** | 对简报目标受众和核心障碍有具体作用 | 回到简报重定切口，不继续润色旧句 |
| **创意** | 一个不落俗套且第一眼能懂的新联系或表达机制 | 推翻换切口，绝不只换形容词 |
| **品牌** | 产品证据、服务或品牌资产是作品成立的机关 | 把品牌焊进创意机制，不只放落款 |
| **执行** | 一条真标题、一张可描述画面或可拍场景 | 实写可用样稿，不用提案术语搪塞 |
| **媒介** | 真正利用了观看、收听、停留或转发的媒介条件 | 重设图文/声画分工或位置逻辑 |
| **影响** | 与商业/传播目标一致的可检验结果路径 | 严格区分“预期验证计划”与“已有结果” |

## 4. 三个反事实测试（Stage 4 必过死关）
1. **换品牌测试**：把品牌名换成头号竞品，作品有任何损失吗？若完全无损则专属性失败；可共享的品类利益必须用独特表达机制或品牌专属事实加固，严禁编造独家功能。
2. **去解释测试**：删掉所有策略 PPT 阐述，只留下最终作品，目标受众还能一眼接住核心意思吗？接不住就修作品本身，绝不靠旁白找补。
3. **换媒介测试**：把这套表达平移到任何其他载体都一模一样吗？若是，检查是否浪费了当前媒介独有的物理/交互机会（不为特殊而特殊，但不错过最佳杠杆）。

## 5. 原创性核查与真实性边界
- **反套作铁律**：可以借鉴底层表达机制，**严禁改写知名广告语冒充原创**（如绝不套用“没有人能真正拥有……只不过为下一代保管”的结构去包装新腕表品牌）。
- **检索声明边界**：用户明确要求原创核查、拟投放关键品牌主张或察觉明显撞车时，在可用检索范围内核查核心短语与概念并如实说明检索范围与发现；**未检索绝不能宣称“全球首创”或“全网无雷同”**（且检索本身也无法证明绝对原创）。

## 6. 概念阶段与真实成效严格分开
- 概念提案阶段只写**预期作用与验证方法**，严禁编造触达量、增长率、获奖结果或虚构受众反应。
- 验证设计紧扣目标：比较新旧稿在受控受众、投放条件与测量窗口下的主张理解度、品牌归属、主动转述、有效咨询或实际成交；无实测数据就坦诚“尚未验证”。
- 只改一句文案或写一张海报时，不强附冗长测量计划；需要整套 campaign 时，交出可执行核心作品、扩展机制与主要实施依赖，不把不存在的服务当成已上线能力。
