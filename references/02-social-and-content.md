# 载体规范：小红书 / 微信公众号爆文 / 朋友圈 / 社媒传播与借势

> 只在任务涉及小红书图文/种草/干货/标题、微信公众号深度爆文、微信朋友圈或社媒传播帖子时加载本文件。

## 1. 核心拉升指标
- **小红书**：点击率（首图大字 + 标题） → 停留时长（前 2 页节奏） → 收藏率（实用模板/清单） → 评论率（站队/求同款/咨询） → 转发率（社交货币）。
- **微信公众号**：打开率（社交体面标题） → 读完率 → **转发率（朋友圈/微信群社交货币，出现象级 10w+ 的第一命门）** → 划线金句数。
- **朋友圈 / 社群**：第一眼熟人可读性 → 直接转给某人的理由 → 明确且单一的下一步动作。

## 2. 强制结构与微观规则

### 2.1 按传播目标决定内容价值（先定动作，再写内容）

| 希望读者做的动作 | 写作时必须解决的核心问题 |
| :--- | :--- |
| **停下来、点开** | 用目标人熟悉的动作、具体疑问或意外产品事实开头，并在正文兑现点击承诺（拒绝标题党）。 |
| **转发** | 想清谁发给谁、为何此刻发；**配图脱离账号和正文后，接收者依然能看懂这句提醒、邀请或心声**。 |
| **收藏** | 交付“怕以后找不到”的可执行模板、测量步骤、选购对照表或避坑参数，让读者照做后再自然收藏。 |
| **关注** | 先在本篇解决一个具体小问题，再点明账号持续提供什么；只有排期已确认才许诺更新频率。 |

### 2.2 小红书微观规则（图文 / 种草 / 干货 / 观点）
- **标题与封面默认长度**：严格遵从用户指定数量与字数；未指定时标题按 12~20 字、封面大字 4~12 字起稿，必须命中“人群锚点 / 具体数字 / 反常识结果”至少两项，严禁书名号文艺无力标题。用户只要标题就只交标题。
- **首图决定 70% 点击**：全案模式下必须给【画面构图建议】+【首图大字报核心文案（强对比色 / Before-After / 情绪或痛点特写）】。
- **4~8 页图文分页节奏**（全案/图文笔记）：
  - 图 1：视觉冲击 + 一句话冲突/结果；
  - 图 2：直接甩结论或最扎心场景痛点（前 2 页定生死，绝不铺垫背景）；
  - 图 3~6：高密度实测/步骤/避坑清单（每页只讲 1 个点，手机端 1 秒扫完）；
  - 尾图：一页总结卡片 + 低门槛评论互动钩子。
- **正文黄金前两行与真实感**：前两行直接切入具体生活动作，不浪费折叠前黄金位；**严禁用伪造“亲测”“昨天客户说”“用了 30 天”假装活人感**，品牌用具体问题、实拍演示和诚实观察说话；不强行“谁懂啊”，不靠羞辱或虚假焦虑博眼球。

### 2.3 微信公众号深度爆文微观规则（1500~3500 字）
- **标题铁律**：微信生态极重“社交体面”与“信息增量”，拒用低俗震惊体；优先【时代切面 + 具体现象 + 反常识洞察】或【精准群体共鸣】（≤22 字）。
- **四段式爆文结构**：
  1. **微观切口引入（200~300 字）**：用真实新闻、具体生活切片或对话开场，严禁“随着社会发展”式宏大叙事；
  2. **剥洋葱式拆解（2~3 个小标题）**：由表象剥到利益、人性或结构真相，每层论点必须配**具体事例、可核对事实或一手观察**；
  3. **升维到时代/群体命名**：把具体现象提炼成大众“早就感受到但一直没词形容”的新视角或概念命名；
  4. **余韵收尾**：不喊空洞口号，用有画面感的收束 + 1 句直击人心的金句落幕。
- **手机端视觉排版**：每段严格 2~4 行；每 300~500 字给小标题或**加粗金句**；全篇预埋 ≥5 句可直接划线或截图发朋友圈的硬核金句。

### 2.4 嘴替、用户原话与热点借势边界
- **嘴替表达**：优先抓用户在真实场景里的犹豫、别扭或一句话动作（如“让一下，我开冰箱”），绝不把改写对白署成“顾客真实留言”，也不把单条留言夸大为“多数人反馈”。
- **热点与梗**：必须核清原意、适用人群与产品关联；声称“热榜/最火”要有对应平台、日期和原始依据；无法核实或离线时，交付不靠虚假热度也成立的稿子，严禁凭空编造“今天最火热梗”。

## 3. Few-Shot 语感校准（必须对齐 ✅ 的颗粒度与笔力）

- ❌ **平庸 AI 写法**：
  - 小红书：“标题：上班族必备的5个收纳技巧！正文：在这个快节奏的时代，租房空间小让人很焦虑。今天分享我亲测超好用的置物架，家人们谁懂啊，快点私信我领链接！”（AI 套话 + 假亲测 + 硬导流限流雷）
  - 公众号：“为什么年轻人不爱发朋友圈了？随着社交媒体的发展，越来越多的人关闭了朋友圈，这背后反映的是现代人的社交焦虑……”（宏大空话 + 陈词滥调）
- ✅ **现象级商业写法**：
  - 小红书（合租门后测量）：“封面大字：【买置物架前，先开门撞一下】｜转发给室友的图：『先别下单！咱俩今晚量一下门后宽和深，再把门推到底看把手撞不撞。』｜收藏测量卡：1. 门后可用宽 2. 门后可用深 3. 门推到底看把手净距。”（目标精准分流、无假亲测、每字可执行）
  - 公众号：“标题：朋友圈三天可见的背后，是成年人最后一块自留地｜开头：上周同学聚会，我点开老王头像，只有一条横线。以前他连吃碗牛肉面都要发九宫格。他喝了口茶说：『微信两千多个好友，一半甲方和同事，发加班怕老板看见，发旅游怕客户觉得我太闲。』”（微观切片切入、社交体面、读完即想转）

## 4. 必交交付物
- **轨道 A（定向快速通道）**：严格按用户要求交付（如只要 3 条 12 字内小红书标题 / 两条 80 字内涨粉与获客短帖 / 朋友圈单条成稿），零多余解释。
- **轨道 B（现象级全案模式）**：按统一区块输出：
  - `[HOOKS]`：5 个不同角度备选标题（结果前置 / 反常识 / 人群点名 / 避坑警示 / 情绪嘴替）；
  - `[MAIN_OUTPUT]`：小红书交【首图 + 4~8 页内页画面与图上大字 + 正文 + 8 个精准搜索长尾标签】；公众号交【转发卡片摘要 + 完整排版正文（含小标题、加粗金句与配图位置）】；
  - `[VIRAL_CLIPS]`：3 句最适合截图发朋友圈/群聊的硬核金句或卡片切片；
  - `[COMMENTS]`：3 条评论区点火/站队/自然咨询引导语；
  - `[SPREAD_PATH]`：从首发平台 → 微信群/朋友圈二次扩散 → 真实可用入口（商品卡/门店/私信咨询边界）的承接路径。

## 5. 专属红队审查清单（Stage 4 必查）
- **首图 / 标题拦截测试**：小红书缩小到双列瀑布流能 1 秒看清利益或冲突吗？公众号转发到朋友圈显得体面有见识，还是像廉价营销号？
- **黄金开场测试**：前两行（小红书）或前 200 字（公众号）有没有半句铺垫废话？点击承诺在正文里兑现了吗？
- **真实性与合规测试**：有没有伪造“亲测/客户原话/当日热榜”？有没有塞“加微信/点击链接”等易限流硬导流词或广告法极限词？
- **独立转发与动作测试**：配图或金句脱离账号后别人看得懂吗？如果带获客目标，入口、需提供的信息与服务范围写清楚且未超边界了吗？
