# 载体规范：品牌主张 / Slogan / 海报 / 户外 / 门店物料 / 社交货币 / 高端与地产

> 只在任务涉及广告语、Slogan、户外大牌、电梯/门店/货架海报、系列平面、包装文案或高端/奢侈品/地产表达时加载本文件。

## 1. 核心拉升指标
1 秒视觉停顿与接住核心意思 → 品牌归属记忆度（换品牌即失效） → 路人拍照/转述的社交货币价值 → 按投放位置自然落地的下一步动作（纯品牌留白除外）。

## 2. 强制结构与微观规则

### 2.1 广告语、海报与系列平面
- **广告语 / Slogan**：优先可复述、可长期使用、与产品事实或品牌资产强绑定，不必押韵，也不必强加 CTA；主张与事实相互支撑，避免绝对化承诺。
- **系列海报**：多张共享同一创意规则，**每张必须贡献新的观察、证据或生活场景**，绝不是把同一个意思换三种说法重说。用户要几张就给几张，不擅自附视频或整套 campaign。
- **图文分工与已有画面核对**：先读图片、线框或画面描述，留意已印在图里的字、尺寸线和按钮。视觉已证明的细节不再重复写；**脱离配图独立传播的纯文字版，必须补回认出产品与关键条件的信息**。
  - 例：面包店图上已印“吐司可买半条”，海报标题只需写「明早想吃，没打算吃一周」；发纯文字群通知时，则需补回“吐司可买半条”。
- **按投放位置分层上版**：

| 投放位置 | 文字安排与分层规则 |
| :--- | :--- |
| **户外大牌 / 电梯海报** | 一级标题让路过的人 1 秒接住一个意思；确需补充利益或交易条件时，再加一行副标题。 |
| **门店促销 / 桌边立牌 / 咨询海报** | 一级给核心主张或优惠，二级补购买理由，三级按需放价格条件、适用范围或证据图注；重要门槛（时段/限同单等）与报价处于相邻可读位置，行动入口紧邻真实收银/预约位置。 |
| **货架价签 / 摊头牌** | 实物与牌子同框入镜，主句可借实物补足意思，让已经进店的人直接挑选、拿取或发给朋友。 |
| **信息流单图 / 独立转发海报** | 缩成缩略图也能读出主句；单图脱离账号流传时，必须保留认出商品、品牌或真实到店/咨询入口的线索。 |

- **交付排版纪律**：交给设计师的文字按实际上版行序交付。只要成稿时，直接给文字与换行；用户要求标层级时再标「一级标题 / 二级文案 / 行动入口」等。副标题若只是把主标题换个说法，立刻删掉。

### 2.2 社交货币与自发传播（让卖点变成双人之间的暗号）
- **绑定产品特点与人际动作**：水果摊写「比初恋还甜」之所以有人拍给伴侣，是因为“甜”同时说通眼前水果和伴侣玩笑（对方还能回“你说哪一任？”）。借鉴机制时，**必须从眼前产品特点重新找切口**，严禁把“比初恋还……”换个词套到别的商品。
- **五大抓手优先选型**：关系嘴替（借产品说不好意思开口的话）/ 互损接话暗号（留出对方必回一句的缺口）/ 态度名片（转发即亮明审美与清醒立场）/ 实用人情（发给搭子刚好用得上）/ 同行暗语（B2B 换一线从业者大实话）。
- **卖点 = 表达心情的开关**：让产品的真实设计/形态驱动一个具体人际动作，拿掉这个特点，情绪或笑点就不再成立。
  - 例：可沿中线撕成两枚书签的电影纪念票 → 「电影看同一场，散场后一人留半张」。（只写“好时光值得珍藏”，换任何纪念品都成立。）
- **B2B / 专业场景的自然转述**：把说话人从“品牌”换成实际使用者（如店长、设计师、合伙人）——在交班、复核或商量开店那一刻，他会怎么顺口发给拍档？只能由销售背出来的押韵口号缺少同行借用理由。
- **双人对话试飞（内部必过）**：选稿前必演一遍——具体谁会拍下哪几个字发给谁？对方能接哪句话或做什么动作？如果只能想到“这广告写得真好”或“哈哈”，说明社交货币不够，重来！**删掉“快转发”“@好友”和抽奖后，内容本身必须依然值得发给某个人。**

### 2.3 高端、奢侈品与地产
- **高价格 ≠ 固定文风**：先看品牌自身语气、价格策略与任务——可以克制、幽默、先锋、热烈或温暖直接。用户明确要求真实促销或到店动作时，照常准确表达，不因“奢侈品”擅自改成“私人鉴赏”。
- **真实依据边界**：只从已知材料、造型、工艺、服务或空间细节提炼辨识度。没有百年历史就不写传承，没有手工证据就不写反复打磨；场景描写不暗示不存在的配套、每户景观、通勤时间或升值预期。
- **留白铁律**：留白是减少解释而保持语义完整，**严禁用“时间、沉默、秩序、不必证明、极致”循环填空**，也不用少数人优越感代替品牌价值。

### 2.4 热点与梗的边界
- 借梗前先核清原意、受众与产品共享的处境；若只剩词面巧合，回归受众日常用语。长期上墙的海报（如挂一年）严禁依赖过期短命梗，必须让没看过原梗的人也能一眼懂。
- 声称“榜首/最火”必须限定在可核对的平台、时间与来源范围内；无榜可查或离线任务，直接交付不依赖热度断言也能成立的成稿。

## 3. Few-Shot 语感校准（必须对齐 ✅ 的锋利度与产品绑定）

- ❌ **平庸 AI 写法（通用情绪 + 空壳词）**：
  - 豪宅海报：“以时间的秩序，礼献少数人的从容；每一扇窗，都是江岸写给城市的诗。”（伪深刻空壳词 + 编造“每一扇窗见江”）
  - 水果摊牌：“好葡萄，甜过初恋！快拍照转发给你的闺蜜一起品尝吧！”（套句式 + 假糖度 + 硬指令转发）
  - 书签留白：“山海自有归期，欢迎常来XX书店选一本好书，扫码加会员享折扣。”（无视不要 CTA 要求 + 通用鸡汤）
- ✅ **现象级商业写法（产品事实即人情动作 / 零空壳）**：
  - 可撕书签纪念票：「电影看同一场，散场后一人留半张。」（撕开结构直接进入人与人之间的关系，拿掉工艺即失效）
  - 整串葡萄摊头牌：「这串你先挑，剩的归我。」/「一串刚够两人分着吃，挑一串带去见想见的人。」（紧扣“整串/分食”动作，朋友间有话可接，自然引导挑选，不编甜度）
  - 办公室下午茶电梯海报：「下午喝茶，算我一杯。 / 现萃原叶茶，3杯45元 / 门店小程序下单」（一眼接住场景、事实与真实入口，无废话）

## 4. 必交交付物
- **默认模式（直出 2.0 成品）**：直接按用户要求交付可直接上版的句数、行数与层级文案（必要时仅配 1 行画面分工），零策略废话、零评分表。
- **显式全案模式（仅当用户明确要全案/扩散包时）**：按 `[HOOKS]`、`[MAIN_OUTPUT]`、`[VIRAL_CLIPS]`、`[COMMENTS]`、`[SPREAD_PATH]` 输出完整方案。

## 5. 专属红队审查清单（Stage 4 必查）
- **1 秒缩略图 / 路过测试**：路人走过电梯或刷过缩略图，离开解释段落能 1 秒读懂核心意思吗？
- **去 Logo / 换产品测试**：换成竞品或删掉产品这项核心特点，这句文案还能同样成立吗？（若毫无损失，立刻重写！）
- **分享接话测试**：能明确说出具体“谁拍给谁，对方回哪句话”吗？删掉转发话术后依然值得分享吗？
- **图文不重复 & 独立存活测试**：有没有重抄图上已印的字？若是独立转发单图，脱离账号后产品和真实入口还在吗？
- **空壳与事实边界测试**：有没有偷塞“秩序/时间/沉默”填空、编造历史材质景观，或在用户要求留白时硬塞 CTA？
