# 按媒介落地

只读取当前任务相关部分。下面是选择标准，不是固定输出表格。

## 广告语、海报、系列

广告语优先可复述、可长期使用及品牌关联，不必押韵或强加CTA。主张与事实证据相互支持，避免无法兑现的绝对承诺。
海报按接触距离和停留时间控制信息层级；远距离户外通常只容纳一个重点。主标题不应依赖长段策略解释。图文配合时，标题不复述画面。
系列保持同一创意机制，让每一张贡献新内容。用户要求几张就给几张，不自动附视频。

## 小红书、朋友圈和社媒

遵循用户数量与长度；未指定时小红书标题可按12—20字、封面4—12字起稿，这是写作默认值，不是平台最新规则。只要标题就只给标题；需要封面或整篇时再补对应内容。
点击承诺必须在正文兑现。不用伪装亲身经历制造“活人感”；品牌可以通过具体问题、演示和诚实观察说话。口语程度由品牌和受众决定，不能强行“谁懂啊”。
不得通过羞辱、群体刻板印象或虚假焦虑制造注意。幽默尽量对准情境、惯性和品牌自己。

## 短视频、品牌片、声音广告

镜头与声音具体可执行，有时长要求则给时间段，并为动作和停顿留空间。口播先按正常语速粗估再朗读核对，不把完整长文塞进15秒。
开头让受众迅速知道为什么值得看；品牌出现时间由创意决定，不固定最后一秒。产品应参与情节或提供证明。
声音广告靠听觉成立，文字双关需听得懂，不能依赖画面解释。只要脚本就交脚本。

## 销售页、促销、招商

围绕最主要障碍安排：清楚的价值 → 可信依据 → 必要条件/限制 → 下一步。价格、期限、优惠门槛不能被修辞隐藏。真实优惠本身有吸引力时，直接说。
招商与复杂服务优先决策相关信息、交付范围和已证实案例，少写抽象使命。不得暗示未经支持的收益或效果。

## 客户案例

用真实处境、困难、采取的行动和可核对结果建立叙事。客户是行动者，不一定要编成悬疑故事。没有姓名、对话和结果就不能补写成事实；示意案例应清楚标记为虚构，不冒充见证。

## 高端、奢侈品、地产

先看品牌自身的语气、价格策略、受众与任务：可以克制、幽默、先锋、热烈或直接；高价格不是固定文风。
从已知材料、造型、工艺、服务或空间细节中选择有辨识度的依据。没有百年历史就不写传承，没有手工证据就不写反复打磨；“想象场景”也不能暗示不存在的配套、景观或通勤时间。
留白应减少解释而保持意义完整，不拿“时间、沉默、秩序、不必证明”循环代替内容。不要用少数人优越感替代品牌价值。
购买或预约任务要给清楚动作；用户明确要求真实促销时正常表达优惠，不因“奢侈品”覆盖需求。

## 卖货任务：让创意推动决策

先判断购买阶段：陌生受众需要快速知道“与我何关”；比较中的受众需要证据、差异和适用条件；临近购买的受众需要消除疑虑并明确交易条件；老客需要真实的复购理由。不要对所有人从头教育，也不要对陌生人只喊下单。

围绕当前最大的购买障碍选择内容：
- 不知道有何用：把功能放进具体使用任务，用事实说明收益。
- 不相信：给用户提供的演示、规格、可核对案例或服务承诺，缺证据就降低承诺，不加夸张。
- 觉得不值：解释总价对应的实际获得、使用频率或替代成本；只有已知数字才能计算，不臆测竞品成本。
- 怕不适合：说明适用人群、选择条件、真实规格和限制，减少买错的不确定性。
- 担心购买风险：写已确认的试用、退换、质保或服务条件，不自行增加保障。
- 没有现在买的理由：有真实时效优惠就准确表达，没有就用明确使用需求推动，不能编造倒计时、缺货或涨价。

可用骨架：**相关的利益钩子 → 关键证据 → 回应主要顾虑 → 真实报价/条件 → 单一清楚行动**。按媒介压缩，不要求短标题塞满五项。不把优惠埋在长篇故事后，也不以创意为由漏掉规格、门槛与截止日期。

渠道调整：
- 电商首屏：迅速说明是什么、适合谁、核心收益；详情页逐项回应决策问题。
- 直播/口播：句子能说出口，先讲这轮购买理由，再说明规格价格和操作；不使用虚假库存或托的见证。
- 私域/销售对话：回应对方当前问题，一次推动一个合适步骤，不把对话写成演讲，不假装与客户熟悉。
- 线下门店/活动：让人看清商品、权益、条件和参与地点/动作。
- B2B/招商：交代业务问题、方案适配、实施条件和可信证据；下一步可为预约演示、索取报价或评估，不强求立即成交。

兼顾品牌与成交时，用一个品牌相关的创意入口承接具体购买证据，CTA保持该品牌的语气。只在用户需要测试或备选时交付不同购买动机的版本；不要把三个近义标题称为A/B测试。

发布前从买家角度复核：我知道卖什么、为何与我有关、凭什么信、交易条件是什么、下一步做什么吗？长页面应回答必要问题，短素材与落地页共同承担信息，不在一行里硬塞全部内容。
