# 按媒介落地

只读取当前任务相关部分。下面是选择标准，不是固定输出表格。

## 广告语、海报、系列

广告语优先可复述、可长期使用及品牌关联，不必押韵或强加CTA。主张与事实证据相互支持，避免无法兑现的绝对承诺。
系列保持同一创意机制，让每一张贡献新内容。用户要求几张就给几张，不自动附视频。

先看图片、线框或用户对画面的描述，留意已印在图里的字、尺寸线和按钮。没有配图的纯文字版要能独立认出产品和关键信息。例：面包店的图上若已印“吐司可买半条”，标题可以只写“明早想吃，没打算吃一周”。同一内容作纯文字通知，要补回“吐司可买半条”。

| 位置 | 怎样安排文字 |
|---|---|
| 户外大牌、电梯海报 | 一级标题让路过的人一眼接住一个意思。有利益或交易条件需要补充，再给一行副标题。 |
| 门店促销、咨询海报 | 一级给主张或优惠，二级补购买理由，三级按需放价格条件、适用范围或证据图注。行动入口紧邻真实的购买或预约位置。重要门槛与报价同处可读位置。 |
| 信息流单图、社媒封面 | 缩成缩略图也能读出主句。单图若独立传播，保留识别商品或理解优惠所需的信息。后面有正文或轮播时，把解释留给后面。 |

交给设计师的文字按实际上版的行序交付。只要成稿时，直接给文字和换行。用户要标层级时再标“主标题／副标题／图注”。副标题若只是把主标题换个说法，就删掉；照片已经证明的细节无需再写一层。

## 商品主图与详情页逐屏

商品列表里的主图要让人认出卖什么、为何值得点开。进入详情后，首屏给核心利益或选择条件。后续每屏回答一个新的购买问题，例如尺寸是否合适、演示能证明什么、下单条件是什么。按用户指定的屏数、已有素材和顾虑选用，不为凑屏数发明卖点。

每屏先写能独立读懂的标题。有新证据或必要条件才写短说明。给定实拍、规格表或开门示意图时，文字负责解释它对选择的意义。例如折叠厚度只能帮助判断闲置时的收纳空间，展开能否放下要看展开尺寸。用户只要上屏文字，就分屏交稿，把设计理由留在内部。

同一份简报可以改写成不同位置的成稿。以下示意均使用“现萃原叶茶，3杯45元，门店小程序下单”这三个事实：

| 位置 | 成稿（每行可直接使用） |
|---|---|
| 写字楼电梯海报 | 下午喝茶，算我一杯。<br>现萃原叶茶，3杯45元<br>门店小程序下单 |
| 同事群里的凑单配图 | 我点茶，还差两位。<br>现萃原叶茶，3杯45元<br>门店小程序下单 |
| 已在门店小程序的商品首屏 | 现萃原叶茶<br>3杯45元 |

## 小红书、朋友圈和社媒

遵循用户数量与长度；未指定时小红书标题可按12—20字、封面4—12字起稿，这是写作默认值，不是平台最新规则。只要标题就只给标题；需要封面或整篇时再补对应内容。
点击承诺必须在正文兑现。不用伪装亲身经历制造“活人感”；品牌可以通过具体问题、演示和诚实观察说话。口语程度由品牌和受众决定，不能强行“谁懂啊”。
不得通过羞辱、群体刻板印象或虚假焦虑制造注意。幽默尽量对准情境、惯性和品牌自己。

根据这篇的主要传播目标决定交付什么价值，相关动作可以由内容自然引出：

| 用户希望读者…… | 写作时解决的问题 |
|---|---|
| 停下来、点开 | 用目标人熟悉的动作、具体疑问或意外的产品事实开头。让他在正文里找到开头答应的答案。 |
| 转发 | 想清谁会发给谁、为何现在发。配图脱离账号和配文后，接收者也能听懂这句提醒、邀请或心声。 |
| 收藏 | 提供以后真能打开来用的东西，如一组测量步骤或选购对照。读者可以照做，再决定是否收藏。 |
| 关注 | 先在本篇解决一个小问题，再点明这个账号还会持续提供什么。只有排期或服务已确认，才许诺具体下期或更新频率。 |

## 社交货币与自发传播

“比初恋还甜”放在水果摊上，“甜”同时说得通两件事：眼前的水果，和各人记忆里的初恋。路人拍给伴侣，对方甚至可以回一句“你说的是哪一任？”这张照片于是有了两个人之间的用途。借鉴这种联系时，从眼前产品重新找切口，避免把“比初恋还……”换个形容词套在别的商品上。

把卖点放进人与人之间的动作。比如一张可沿中线撕成两枚书签的电影纪念票，可以写“电影看同一场，散场后一人留半张”。撕开的设计让同看一场电影的两个人各有东西可留；只写“好时光值得珍藏”，换任何纪念品也说得通。情绪也可以是松口气、想逗朋友、怕给同事添麻烦，取决于这项功能在生活里改变了哪一刻。商家能证明的是产品特点，具体场景可以作为邀约或设想来写。

选稿时，在心里演一次分享：顾客会拍下哪几个字，发给谁？对方可以接什么话，或接下来做什么？如果只能想出“这广告写得真好”，再往前找一个让分享者有所得的理由。可以是替朋友说出心声、送出一句平时难开口的话，或给同事一个真能用的小窍门。只要成稿时，这段推演留在内部。

专业产品也可以成为同行之间的一句提醒。试着把说话人从品牌换成实际使用者：在交班、复核或采购的那一刻，他会怎样提醒同事？一句押韵的功能介绍如果只能让销售来说，就还缺少同行会借用的理由。

按分享时真正带走的东西检查：拍价签时水果也在镜头里，短句可以借画面补足意思；转述一句口号时没有配图，就要靠文字留住商品线索。删去“快转发”“@好友”和奖励后，内容本身应仍有分享的价值。需要验证效果时，看实际有多少人主动转述、配了什么话、还记得什么产品；创作阶段只判断分享理由是否成立。

## 热点与梗

用户给了梗，先弄清原意、谁在用，以及它跟产品共享哪种处境或情绪。写之前试着说出“这群人为什么会把它转给谁、转完还能记得哪一点产品价值”。只剩词面巧合时，回到受众的日常用语。长期张贴的海报尤其要让不熟悉梗的人也看得懂。

声称“今天上榜”“平台最火”要有相应平台、日期和原始帖子或榜单依据。单个帖子只能证明其内容，某时某平台的榜位只支持那个范围。用户给定的趋势资料可按其范围使用。无法核实时，给不依赖热度断言也成立的稿子；用户要求说明选题依据时再简述证据边界。依据放在稿外，保留“只给成稿”的交付形式。

## 短视频、品牌片、声音广告

镜头与声音具体可执行，有时长要求则给时间段，并为动作和停顿留空间。口播先按正常语速粗估再朗读核对，不把完整长文塞进15秒。
开头让受众迅速知道为什么值得看；品牌出现时间由创意决定，不固定最后一秒。产品应参与情节或提供证明。
声音广告靠听觉成立，文字双关需听得懂，不能依赖画面解释。只要脚本就交脚本。

## 销售页、促销、招商

围绕最主要障碍安排：清楚的价值 → 可信依据 → 必要条件/限制 → 下一步。价格、期限、优惠门槛不能被修辞隐藏。真实优惠本身有吸引力时，直接说。
招商与复杂服务优先决策相关信息、交付范围和已证实案例，少写抽象使命。不得暗示未经支持的收益或效果。

## 商业文案的行动收口

同一句主标题既可以让人想拍照，也可以把人引向商品。先写出值得分享的那句，再从顾客站的位置往下走一步：

| 顾客现在在哪 | 怎么收口 |
|---|---|
| 街上、社区群里 | 目标是到店时，给认得出的店名、位置或已确认的门店入口，并带上值得去的理由。店名地址随图片展示时可借用；图片会被单独转发时，确认关键线索还在。 |
| 已经站在货架前 | 让人挑、拿、比较或向店员问一个具体问题。例如“挑一串，带去串门”。已在店里的顾客不需要再找店。 |
| 社媒帖子或转发出去的单图 | 有商品卡就接商品，有门店地址就接到店，提供咨询就说清向谁问什么。选实际存在的一条。正文可以承接封面；若任务要求单图独立获客，线索要跟着图片走。 |
| 商品页、预约页 | 利益和必要条件放在做决定的位置。已确认的购买或预约控件可以完成最后一步，正文补选择依据。没有现成控件且用户要按钮文案时，写出对应动作。 |

入口缺失时先用已知触点。若连顾客该去哪或联系谁都无法判断，且这会改变成稿，只问缺失的关键信息；交草稿时可标出待填的入口。不得替商家开通私信接单、预留商品、免单试吃等服务。想验证闭环，就看对应终点的行为，例如到店核销、有效询问或支付订单；拍照和点击可以帮助判断人在哪一步停下。

## 咨询与留资

让合适的人认出自己所处的阶段，再写明通过哪个已知入口、提供哪一项必要信息、能换来什么具体答复。保留影响行动的门槛和服务范围。入口或权益未知时，可邀请对方就具体问题咨询，避开未证实的免费、时限和交付承诺。

例如，门店若确实提供厨房图纸初评，可以写“正在定厨房布局？私信发带尺寸的平面图，帮你标出两人做饭容易堵的位置”。只提供到店演示的品牌，就把读者引向预约演示。已有的报名表已经收了尺寸，无需在文案里再索取一次。

## 客户案例

用真实处境、困难、采取的行动和可核对结果建立叙事。客户是行动者，不一定要编成悬疑故事。没有姓名、对话和结果就不能补写成事实；示意案例应清楚标记为虚构，不冒充见证。

## 高端、奢侈品、地产

先看品牌自身的语气、价格策略、受众与任务：可以克制、幽默、先锋、热烈或直接；高价格不是固定文风。
从已知材料、造型、工艺、服务或空间细节中选择有辨识度的依据。没有百年历史就不写传承，没有手工证据就不写反复打磨；“想象场景”也不能暗示不存在的配套、景观或通勤时间。
留白应减少解释而保持意义完整，不拿“时间、沉默、秩序、不必证明”循环代替内容。不要用少数人优越感替代品牌价值。
购买或预约任务要给清楚动作；用户明确要求真实促销时正常表达优惠，不因“奢侈品”覆盖需求。

## 卖货任务：让创意推动决策

先判断购买阶段：陌生受众需要快速知道“与我何关”；比较中的受众需要证据、差异和适用条件；临近购买的受众需要消除疑虑并明确交易条件；老客需要真实的复购理由。不要对所有人从头教育，也不要对陌生人只喊下单。

围绕当前最大的购买障碍选择内容：
- 不知道有何用：把功能放进具体使用任务，用事实说明收益。
- 不相信：给用户提供的演示、规格、可核对案例或服务承诺，缺证据就降低承诺，不加夸张。
- 觉得不值：解释总价对应的实际获得、使用频率或替代成本；只有已知数字才能计算，不臆测竞品成本。
- 怕不适合：说明适用人群、选择条件、真实规格和限制，减少买错的不确定性。
- 担心购买风险：写已确认的试用、退换、质保或服务条件，不自行增加保障。
- 没有现在买的理由：有真实时效优惠就准确表达，没有就用明确使用需求推动，不能编造倒计时、缺货或涨价。

可用骨架：**相关的利益钩子 → 关键证据 → 回应主要顾虑 → 真实报价/条件 → 单一清楚行动**。按媒介压缩，不要求短标题塞满五项。不把优惠埋在长篇故事后，也不以创意为由漏掉规格、门槛与截止日期。

渠道调整：
- 电商按上面的“商品主图与详情页逐屏”安排，价格、适用条件和购买入口放在读者作决定的位置。
- 直播/口播：句子能说出口，先讲这轮购买理由，再说明规格价格和操作；不使用虚假库存或托的见证。
- 私域/销售对话：回应对方当前问题，一次推动一个合适步骤，不把对话写成演讲，不假装与客户熟悉。
- 线下门店/活动：让人看清商品、权益、条件和参与地点/动作。
- B2B/招商：交代业务问题、方案适配、实施条件和可信证据；下一步可为预约演示、索取报价或评估，不强求立即成交。

兼顾品牌与成交时，用一个品牌相关的创意入口承接具体购买证据，CTA保持该品牌的语气。只在用户需要测试或备选时交付不同购买动机的版本；不要把三个近义标题称为A/B测试。

发布前从买家角度复核：我知道卖什么、为何与我有关、凭什么信、交易条件是什么、下一步做什么吗？长页面应回答必要问题，短素材与落地页共同承担信息，不在一行里硬塞全部内容。
