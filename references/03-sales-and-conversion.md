> 在所有明确卖货、促销、电商、详情页、直播口播、私域回复、咨询留资、B2B 招商、客户案例，以及「品牌 + 转化双目标」需要落实商业行动收口时加载本文件。

## 1. 核心拉升指标
主图点击率 → 首屏停留与理解速度 → 关键购买障碍消除率 → 有效咨询 / 到店核销 / 下单转化率（且客诉与虚假承诺率为零）。

## 2. 强制结构与微观规则

### 2.1 卖货底层逻辑：按购买阶段与最大障碍出牌
- **先判断购买阶段**：
  - 陌生受众：先快速交代“与我何关”；
  - 比较中受众：给真实证据、具体差异与适用条件；
  - 临近购买受众：消除最后一公里疑虑，把报价与交易条件写透；
  - 老客：给真实的复购或增购理由。
- **对准当前最大购买障碍精准破局**：
  - **不知道有何用**：把功能放进具体使用任务，用事实讲清收益；
  - **不相信**：只用已有演示、规格、可核对案例或已确认服务承诺；缺证据就降承诺，绝不夸张；
  - **觉得不值**：拆解总价对应的实际获得、使用频次或替代成本（只用已知数字算，绝不臆测竞品成本）；
  - **怕不适合**：交代适用人群、选择条件、真实规格与限制（如折叠厚度≠展开尺寸，载重上限≠任意重物）；
  - **担心购买风险**：只写已确认的试用、退换、质保条件，绝不擅自加保障；
  - **没有现在买的理由**：有真实时效优惠准确写明，没有就用明确使用需求推动，**严禁编造倒计时、缺货或即将涨价**。
- **转化五段骨架**：**相关利益钩子 → 关键证据 → 回应主要顾虑 → 真实报价/交易条件 → 单一清楚行动**。按媒介压缩，不要求短标题塞满五项；绝不把价格、门槛、截止日期藏在长故事或修辞后面。

### 2.2 商品主图与详情页逐屏规范
- **主图**：在商品列表里 1 秒让人认出卖什么、为什么值得点开。
- **详情逐屏**：首屏给核心利益或选择条件；后续**每屏回答一个新的购买问题**（收纳怎么放、承重/效果怎么证、能否过窄门、下单条件是什么），按用户指定屏数与已有素材写，不为凑屏数发明卖点。
- **规格事实边界**：每屏标题必须独立可读；给定实拍图、规格表或示意图时，文字解释它对选择的意义（如“折叠厚 9cm”只证明闲置收纳，过窄门必须提示核对“展开宽度与门净宽”，未知尺寸绝不代为保证）。
- **同一简报跨位置写法对照**（事实：现萃原叶茶，3杯45元，门店小程序下单）：

| 投放位置 | 直接可上版成稿 |
| :--- | :--- |
| 写字楼电梯海报 | 下午喝茶，算我一杯。<br>现萃原叶茶，3杯45元<br>门店小程序下单 |
| 同事群凑单配图 | 我点茶，还差两位。<br>现萃原叶茶，3杯45元<br>门店小程序下单 |

### 2.3 商业文案的行动收口（先写值得分享的，再走真实下一步）

| 顾客现在在哪 | 行动收口怎么落地 |
| :--- | :--- |
| **街上、社区群里** | 目标到店时，给认得出的店名、地址或已确认门店入口 + 到店理由；单图独立转发时确认位置线索跟着图走。 |
| **已站在货架 / 柜台前** | 引导当场挑、拿、比较或向店员问一个具体问题（如“挑一串，带去串门”），不要让已在店里的人再去“找店”。 |
| **社媒帖子 / 独立转发单图** | 有商品卡接商品，有门店地址接到店，有电话/咨询入口就说清向谁问什么——只选真实存在的一条。 |
| **商品页 / 预约页** | 利益与交易条件放在决策位；页面已有“立即购买/预约”控件直接承接，不再额外乱导流；需要按钮文案时写出对应动作。 |

- **入口缺失处理**：先用已知触点；连去哪或联系谁都无法判断且会改变成稿时，简短追问缺失入口（交草稿标 `[待补入口]`）。**严禁替商家虚构私信接单、免费量尺、预留商品、配送或赠品。**

### 2.4 渠道细分：咨询留资、私域、直播、B2B 招商与客户案例
- **咨询与留资**：让对的人认出自身阶段 → 指明已知入口 → 说明提供哪项必要信息 → 明确换来什么具体答复（如“私信发带尺寸的平面图，帮你标出两人做饭容易堵的位置”）。报名表已收集的信息不重复索取；未证实不承诺“免费/秒回/全案设计”。
- **私域 / 销售对话**：直面顾客当下顾虑，一次推进一个合适步骤，不把聊天写成演讲，不假装老熟人；遇未知参数如实说明核对方法。
- **直播 / 口播**：句子能顺口说出来，先讲本轮购买理由，再讲规格、价格与下单操作，严禁虚假库存与托的见证。
- **B2B / 招商**：直奔业务问题、方案适配、实施条件与可核对案例，少写抽象使命，不暗示未经证实的回报或收益翻倍。社媒招商海报优先植入**「同行暗语 / 合伙人转发理由」**（让人看到后想直接转给搭档、配偶或同行商量：“咱俩要开店，别去卷奶茶了，先去看看这家”），而非官方自夸口号。
- **客户案例**：按「真实处境 → 具体困难 → 采取动作 → 可核对结果」写，客户是行动者；无姓名、对话与真实数据时绝不冒充真实见证，示意案例必须明确标注“虚构示例”。

## 3. Few-Shot 语感校准（必须对齐 ✅ 的转化清晰度与克制）

- ❌ **平庸 AI 写法（虚标承诺 + 掩盖条件）**：
  - 详情页：“9cm 极致纤薄折叠手推车，轻松穿过任何窄门，一次拉两袋大米毫无压力，限时抢购错过涨价！”（把折叠厚度冒充过门宽度 + 虚构承载表现 + 假倒计时）
  - 获客短帖：“厨房不好用？私信我免费领全套大师定制图纸，24小时出方案！”（擅自承诺免费、全套图纸与时限）
- ✅ **现象级商业写法（障碍直击 + 证据扎实 + 闭环清晰）**：
  - 详情页三屏：「屏1：闲置不占地｜折叠后厚 9 厘米，可塞进门后或柜侧缝隙。」「屏2：买菜拉货看上限｜额定载重 25 公斤，日常整箱采买先对照单次总重。」「屏3：过窄门先量宽｜下单前请核对展开宽度与自家门净宽（展开尺寸待补）」（逐屏解决收纳/载重/过门三大顾虑，零虚假承诺）
  - 咨询收口（已有门店电话的窗帘图）：「怕买回去遮不住早上的太阳？ / 打图上电话，直接问顾问你家朝向选哪档遮光。」（直击顾虑 + 绑定已有电话 + 降低开口门槛）

## 4. 必交交付物
- **默认模式（直出 2.0 成品）**：直接交付可直接上版/发送的促销、详情逐屏、招商海报、官网首屏或私域回复（社媒买货/招商海报自带社交货币与清晰行动收口），零冗长策略。
- **显式全案模式（仅当用户明确要全案/扩散包时）**：按 `[HOOKS]`、`[MAIN_OUTPUT]`、`[VIRAL_CLIPS]`、`[COMMENTS]`、`[SPREAD_PATH]` 输出完整方案。

## 5. 专属红队审查清单（Stage 4 必查）
- **买家五问自查**：站在真实买家视角读一遍——我知道卖什么、与我何关、凭什么信、全部交易条件是什么、下一步点哪或去哪吗？
- **社交货币与转发测试（社媒卖货/招商必查）**：顾客会不会发给同事/朋友合买或炫耀？创业者会不会转给合伙人/家人商量？拿掉产品特点，这句转发理由还成立吗？
- **事实边界零越线**：有没有把功能推导出未经证明的效果？有没有隐藏门槛、编造优惠/库存/免费服务/客户证言？
- **场景与入口匹配**：已在店里的人有没有被叫去“导航找店”？独立传播图把入口带走了吗？已有购买按钮的页面有没有多余导流？
- **双目标平衡测试**：品牌 + 卖货双目标时，创意是否自然承接了购买理由，而不是前戏好玩、收口生硬？
